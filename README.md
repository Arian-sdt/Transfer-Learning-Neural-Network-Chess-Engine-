# Neural Network Chess Engine

Our project aims to build a Chess AI system that uses a Neural Network model to compete with the Stockfish chess engine. As a supervised learning task, the neural network is trained on the PGN dataset of chess games from the Lichess1 Elite Database and simulated games. The inputs are position data from each chess game played in the form of a 3-way tensor, outputting as integer-based (one-hot predictions) from the input state, which translates to moves on the board.



Requirments include: 
 - Python 3.9+ 
 - Jupyter Notebook
 - Apache Spark 
 - Pandas and Numpy 
 - TensorFlow 
 - Python chess, chess.pgn, chess.engine 
 - Stockfish Chess Engine

## List of Files, their purpose and how to run them 

### Data Processing 
- **CsvToPpg.py**: 
  - Purpose: Python using pandas and chess.pgn to convert CSV to PGN 
  - How to run: The input and output files are hard coded "python3 csv_to_pgn.py"
- **PgnToCsv.py**: 
  - Purpose: Python using pandas and chess.pgn to convert PGN to CSV 
  - How to run: The input and output files are hard coded "python3 pgn_to_csv.py"
- **Simulate.ipynb**: 
  - Purpose: jupyter notebook playing stockfish against itself and collecting data for training
  - How to run: Run the indiviual cells 
- **FilteringGamesPgnExample.py**: 
  - Purpose: Python using Chess.PGN to filter the data set as 
  - How to run: The input and output files are hard coded "python3 FilteringGamesPgnExample.py" 
- **FilteringGamesCsvExample.py**: 
  - Purpose: Python using Spark to filter the data set as 
  - How to run: The input and output files are to be given in the command line coded "spark-submit FilteringGamesCsvExample.py input_directory output_directory"

### Accuracy and Model Evaluation
- **Test.ipynb**: 
  - Purpose: Python script used to test the trained model against the stockfish model
  - How to run: Run the indiviual cells 
- **Accuracy.py**: 
  - Purpose: Python script evaluating a PGN file of games and recording the number of inaccuracies, mistakes, and blunders for each game, writing it to a CSV
  - How to run: The input and output file names are hard coded, edit them as you want and run using "python3 accuracy.py"
- **PandasConclusion.py**: 
  - Purpose: Python script using pandas to perform statistical tests and generate graphs
  - How to run: The input and output file names are hard coded, edit them as you want, run using "python3 pandas_conclusion.py"

### Data File Examples
- **ModelAccuracyExample.csv**: includes an example of the results generated by accuracy.py
- **GameSetExample.pgn/**: includes the stockfish simulated filtred data set in CSV format(ONLY PARTIAL DATA)
- **GameSetExample.csv/**: includes the stockfish simulated filtred data set in PGN format(ONLY PARTIAL DATA)
